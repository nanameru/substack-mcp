# Substack 運用ベストプラクティス（要点）

このファイルは Substack 運用のフレームワークと実務上の判断材料を集めた**Skill 内部のリファレンス**です。
記事や Note を作るときに「どのフレームに沿って書くか」「何を選ぶか」を決める際の、AI 側の判断軸として参照する。

> 本資料は Substack 公式ドキュメント・公知の発信フレームワーク（Nicolas Cole の Voice/Content/Format など）・
> 一般的な運用知見を、Skill 内部用に再構成したもの。引用元の固有の文章は含まない。

---

## 1. ポジショニング・ステートメントの型

新規ユーザーとの最初の会話で、まずこれを 1 文に落とし込む。AI が代筆する場合の型：

> 「私は **[ターゲット]** が **[変化・成果]** を得られるよう、**[トピック]** について発信しています」

埋めるときのコツ：
- **ターゲット**：読者の本音や違和感を含める（例：「専門用語ばかりで疲れた人」）
- **変化・成果**：動詞で具体化（「節約する」より「コピペ作業をやめる」）
- **トピック**：その人にしか書けない切り口（実績の数字・固有経験）

この 1 文は、プロフィール / 概要ページ / ウェルカムメール / 購読登録ページ全部の核になる。

---

## 2. 差別化の 3 軸（Voice / Content / Format）

Nicolas Cole が広めたフレーム。発信の差別化は、3 軸のいずれかをずらせば成立する。

| 軸 | 意味 | 例 |
|---|---|---|
| Voice | 文体・トーン・リズム | 論理的 / 親しみ / 内省的 / 詩的 |
| Content | テーマ・トピックの組み合わせ | AI × 子育て / SaaS × 田舎暮らし |
| Format | 見せ方・モダリティ | 長文 / 図解 / 動画 / 音声 / データ |

全部で勝つ必要はなく、**1 つ尖らせる**のが基本方針。

---

## 3. コアトピックは 1〜3 個に絞る

「この人 = ○○の人」という認識を成立させるため、コアトピックは最大 3 つ。
迷ったら以下の交点を探す：

1. 自分が書きたいこと
2. 読者が困っていること
3. その交点

---

## 4. コンテンツ形式 × 配信リズム

Substack には複数のコンテンツ形式がある。1 形式に依存しないのが続けるコツ。

| 形式 | 役割 | 推奨頻度 |
|---|---|---|
| 長文記事 | メインの読み物 / メール配信される | 週 1（最低ライン） |
| Notes | 短文 SNS 的な発信、フィード露出 | 平日 3〜5 本 |
| ポッドキャスト | 音声派・通勤層へのリーチ、文字起こしも自動 | 週 1 〜 隔週 |
| 動画 | 顔を出す / プロセスを見せる | 月 1 〜 |
| Live / Chat | 既存購読者との関係深化 | 月 1 〜 |

**継続が最大のドライバー**。書けない週は形式を変えてしのぐ（長文の代わりに Notes だけ など）。

---

## 5. プロフィール / 概要ページに入れるべき要素

弱いプロフィール（曖昧で誰向けか分からない）はクリック後に離脱される。最低限これを入れる：

1. 何をしている人か（権威性・経歴）
2. 発信テーマ
3. 誰に向けて書いているか
4. 読者が何を得られるか

複数 SNS で**同じ顔写真・同じ表記**を使う（読者が「あ、この人だ」と一瞬で気づける）。

## 6. Substack 設定の現場知（推奨設定）

Substack の設定は項目が多い。日本語ユーザー向けに迷わない初期値：

| 項目 | 推奨 | 理由 |
|---|---|---|
| 言語 | 日本語 | UI 表示が日本語になる |
| Pledge（プレッジ） | **OFF** | 日本人読者には UI が分かりにくく、購読自体を敬遠される |
| 購読者紹介プログラム | ON、3 / 5 / 15 人など段階制 | 拡散の起点 |
| メール認証必須（ウェルカム） | OFF | Substack の場合は捨てメアド登録が少ないので必須化のメリット < 登録率低下のデメリット |
| 自動シェア | お好みで | YouTube / LinkedIn 連携で多媒体拡散できる |
| ナビゲーションバー | 「概要」「アーカイブ」を非表示にして「**ウミノについて / 過去の記事**」など分かりやすい日本語にカスタム | 標準名は伝わりにくい |

## 7. ホームページ（Publication Home）の設計

- **ピン留め記事**は「最新」ではなく **バズった記事 / 自己紹介記事 / リードマグネット記事** にする
- **ヒーロー（Hero）レイアウト**は「Newspaper（新聞）」が初期訪問者向けに有効
- **ブランドカラー（Accent）と背景色**は 3 色以内・コントラスト比 7:1 以上
- **カバー画像のソーシャルプレビュー**は 1456 × 1048（14:10）が公式推奨。ヒーロー用なら 1456 × 819（16:9）

---

## 8. 記事を出すときのチェックリスト

執筆フローの最後に確認する：

- [ ] 序盤と末尾に **購読ボタン**を配置（最大 2 つ、増やしすぎない）
- [ ] **ソーシャルプレビュー画像**（カバー）は設定済み
- [ ] **タグ**を 2〜5 個設定
- [ ] **タイトル A/B テスト**を使えるなら設定（Substack 標準機能）
- [ ] **メール送信 ON/OFF** を意図して選択
- [ ] **配信時刻**は読者の生活時間（平日朝 7 時台 / 週末午前など）

## 9. 成長施策（無料購読者を増やす）

優先度順で 4 つ：

1. **継続発信**（週 1 を死守）— これが最大ドライバー
2. **おすすめ機能の活用** — 関連クリエイターをおすすめ → 相互おすすめが起きる
3. **他媒体からの誘導** — X 固定ポスト / note 末尾 / プロフィールリンク全部に Substack URL
4. **Notes での日常露出** — 平日 3〜5 本、他人の Notes にもリスタック・リプライで関係構築

ダッシュボードで見る数字：
- **メール開封率**：30% で健全、50% 以上で優秀、20% 以下は要注意（タイトル / 配信時間を見直す）
- **クリック率**：5〜10% で健全、15% 以上で優秀（本文構成 / CTA 配置を見直す）

## 10. 有料購読の判断軸

公式が示す「有料化を検討するタイミング」の 4 サイン：

1. 週 1 以上の継続発信ができている
2. メール開封率が 30% 以上を 3 ヶ月以上維持できている
3. 読者から「課金したい」という声がある
4. 自分の金銭目標（月 / 年いくら）が明確

これが揃わない段階では**無料発信に集中**して購読者リストを育てる方が、結果として有料化時の伸びが大きい。

### 価格設計の基準

- Substack の月額最低は **$5/月**（プラットフォーム側の制約）
- 年額は月額 × 12 より割引するのが慣例（実質 2 ヶ月分割引が多い）
- Founding Member は年額の 3〜5 倍が目安。1on1 / 限定コミュニティ / 著作物などを特典に

### 手数料

おおよそ **約 14%**（Substack 10% + Stripe 決済 3.6% + Stripe Billing 0.7%）

### 4 つのオファー形式（記事以外）

「記事を増やす」だけだと有料化はうまくいかない。**より深いアクセス + 明確な成果**が鍵。

1. **E-book / PDF ガイド**：手元保存できる実用ガイド（10〜30 ページ）
2. **ライブ月例セッション**：Q&A / ワークショップ / グループコーチング
3. **ツール / テンプレート**：Notion / スプレッドシート / 提案書ひな形
4. **ミニコース / ワークショップ**：1 つの成果に絞った 30〜90 分の学習体験

自分の強み（書く / 話す / 整理する / 教える）に近い形式から始める。

## 11. 30 日 → 100 人購読者ロードマップ（参考）

Skill が「立ち上げ計画」を聞かれた時に提示するためのテンプレ。
ユーザーに合わせて配信曜日や形式を調整する。

### Day 1〜2（最初の週末）：立ち上げ完走
- 戦略（ポジショニング 1 文 / コアトピック）を確定
- Publication 作成・ブランディング設定
- プロフィール / 概要ページ
- 最初の記事を 1 本公開
- Notes を 1 本投稿
- SNS で告知

### Day 3〜7：習慣の助走
- 既存 SNS から導線設置（X / note / その他）
- 関連クリエイターをおすすめ設定
- Notes を毎日 1 本

### Week 2〜4：配信リズムの固定
- 週 1 の長文記事を死守
- Notes 平日 3〜5 本
- 相互フォロースレッドに参加 / 主催
- ダッシュボードの数字（開封率・クリック率）を週次で確認

### Month 2〜4：100 人到達まで
- リサイクル（過去記事のフレーズを Notes 化）
- 紹介プログラム（3 / 5 / 15 人タイア）の運用
- ライブ動画 / チャットスレッド試行
- いちばん反応が良かった記事をピン留めに更新
- ウェルカムメールにリードマグネット（特典）を仕込む

## 12. やってはいけないこと（アンチパターン）

- ❌ コンテンツを 5 つも 10 つもテーマ分散させる（誰の記憶にも残らない）
- ❌ 最初から完璧を狙う（60 点で出す、続けながら磨く）
- ❌ 有料化を急ぐ（リスト育成が先）
- ❌ Pledge を ON のまま放置（日本人ユーザーが混乱して離脱）
- ❌ アイキャッチに AI 生成の崩れたテキストを焼き込む（必ず PIL 等で別レイヤー）
- ❌ Note にハッシュタグを大量に並べる（X 文化を持ち込まない、Substack はリスタック / リプライ文化）
- ❌ 連投で全フォロワーに通知爆撃（Notes は適度に）
